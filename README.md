# 🛒 E-Commerce Web App

A responsive and fully functional e-commerce web application built with React.js, Tailwind CSS, Firebase, and Razorpay. The application includes user authentication, product listings, shopping cart, order management, payment integration, and an admin dashboard.

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js 18 or higher
- npm or yarn
- Firebase account
- Razorpay account

### Installation

#### 1. Clone the repository

```bash
git clone https://github.com/Harshprajapati10939/E-Commerce-Web-App-Project.git
```

#### 2. Navigate to the project directory

```bash
cd E-Commerce-Web-App-Project
```

#### 3. Install dependencies

```bash
npm install
```

#### 4. Create an environment file

Create a `.env` file in the root directory and add your credentials:

```env
VITE_FIREBASE_API_KEY=your_firebase_api_key
VITE_FIREBASE_AUTH_DOMAIN=your_firebase_auth_domain
VITE_FIREBASE_PROJECT_ID=your_firebase_project_id
VITE_FIREBASE_STORAGE_BUCKET=your_firebase_storage_bucket
VITE_FIREBASE_MESSAGING_SENDER_ID=your_firebase_messaging_sender_id
VITE_FIREBASE_APP_ID=your_firebase_app_id
VITE_RAZORPAY_KEY_ID=your_razorpay dev
```

The application will run at:

```text
http://localhost:5173
```

Never commit your real Firebase or Razorpay credentials to GitHub.

Use `.env` for local development and add `.env` to your `.gitignore` file.

Example:

```text
.env
.env.local
```
